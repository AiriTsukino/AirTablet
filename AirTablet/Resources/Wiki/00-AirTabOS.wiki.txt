# Quick start
- Choose the bundled apps you want during Welcome. You can change them later in Settings > Apps.
- Use the gesture bar at the bottom to return Home without unloading the app you were using.
- Click the status indicators in the upper-right corner to open Control Center.
- Use the upper side button to lock or unlock the tablet position.
- Use the lower side button to minimize. Press the restore button on the mini tablet to return to full size.
- Open Settings to change appearance, app availability, status bar options, and migration settings.

> tip: Returning Home, minimizing, or switching apps does not disable bundled apps. Enabled apps continue running in the background.

# Control Center
Control Center is a full-screen quick view drawn above the current tablet app. Open it by clicking the status indicators in the upper-right corner. Close it by clicking the same status area again or by clicking the Home gesture bar. The app underneath remains open and does not receive clicks while Control Center is visible.

## Adding and removing widgets
- A new Control Center starts with one Add widget tile.
- Click Add widget, then choose a control or live summary from an enabled bundled app.
- After adding a widget, another Add widget tile appears while space and unused widgets remain.
- Click the minus button in a widget's upper-right corner to remove it.
- Widget choices are saved locally and return the next time AirTablet starts.
- Long widget text scrolls so the complete value or description can be read.

## Live controls and summaries
- AutoGreet: toggle auto-greeting, see current visitors, or check the greeting queue.
- BarManager: view the bar jackpot or current-night sales.
- GambaAssistant: view Blackjack table state or Death Roll tournament progress.
- MacroDeck: run four assigned macros from the active venue profile.
- RaffleManager: view ticket totals, contestants, jackpot, and projected payout information.
- ShiftKeeper: view current shift timers or scheduled staff currently on shift.
- ShoutRunner: view the current advertising route and its status.

Controls use the same local app configuration as their full app. For example, changing Auto-greet in Control Center immediately changes the toggle inside AutoGreet, and changing it inside AutoGreet immediately updates Control Center.

> tip: A widget may show a setup message such as No venue when its app needs an active venue, profile, session, or other selection before live data is available.

# Settings reference
## General
- Run welcome setup: disables the bundled app selections and replays onboarding without deleting the apps' own configuration files.
- Anchor mini tablet: places the mini tablet at the selected corner when collapsing. With anchoring off, full and mini positions are remembered separately.
- Startup animation: controls the short AirTablet loading screen.
## Appearance
- Theme colour: changes AirTabOS and compatible app/overlay accent colours.
- Wallpaper: choose a local image, clear back to the default, and set opacity. A 16:9 image fits best.
## Apps
Enable, disable, or retry bundled apps. Disabled apps remain visible on Home with a red X, and their app-specific automation does not run. Enabling an app starts it without requiring a plugin reinstall.
## What's New
Shows bundled release notes grouped by date and version. Opening this page marks the current AirTabOS version as read.
## Status Bar
Choose 12/24-hour time and whether battery information is shown.
## Migrate Configs
Copies supported settings from the original standalone plugins. Original files are not modified. Repeating migration may overwrite changes made inside AirTablet with values from the old plugins.
## About
Shows the installed AirTabOS version and Ko-fi supporter list.

# Moving and recovery
- Unlock the tablet before dragging the full tablet.
- Full and mini tablet positions are saved independently unless mini anchoring is enabled.
- Use /airtabletrecovery if the tablet is lost off-screen or a monitor layout changes. It restores the full or mini tablet to the active game screen.

# Troubleshooting
## Tablet does not open at character select
This is intended by default. AirTablet waits until your character is loaded into the game unless you enable the show AirTablet before character login option in the settings.
## An app has a red X
The app is disabled. Open Settings > Apps and enable it.
## An enabled app reports that it did not start
Use Retry in Settings > Apps, then check the Dalamud log if it fails again.
## Tablet is on a disconnected monitor
Run /airtabletrecovery after logging into your character.
## A Control Center widget has no live value
Open the full app and select any venue, profile, session, or route it requires. Disabled apps and incomplete setups cannot provide live widget data.
