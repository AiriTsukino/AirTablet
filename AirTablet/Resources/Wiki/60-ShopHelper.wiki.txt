# Quick start
- Open a supported shop in FFXIV.
- Open ShopHelper or enable the setting that opens it automatically with a shop.
- Select the desired shop item.
- Enter an exact quantity, or enable Stacks and enter the number of stacks.
- Review the calculated total and complete the purchase.

# Quantity modes
## Exact quantity
The number field represents the exact number of items to purchase.
## Stacks
The number field represents stack count. Stack size is configurable and defaults to 99, so 2 stacks at 99 means 198 items.

# Automatic opening
When Open ShopHelper automatically when a shop opens is enabled, AirTablet brings ShopHelper forward and loads the detected shop even if the tablet is minimized or currently displaying another app.

# Purchase settings
- Default plain number supplies the initial exact quantity.
- Default stacks supplies the initial stack count.
- Stack size controls how many items each requested stack represents.
- Show confirmation before buying adds ShopHelper's item/quantity/cost review.
- Auto-confirm Yes/No purchase prompts can accept the game's standard confirmation while a queued ShopHelper purchase is active.

During a multi-step purchase, Cancel queue stops remaining queued quantity operations; it cannot undo items already bought.

# Safety and compatibility
ShopHelper reads the active supported shop and uses the game's shop controls. Always review the item, quantity, currency, and total before confirming a large purchase.

# Debug Log
The Debug Log records shop detection and purchase preparation details. Include relevant lines when reporting a shop that is not recognized.

# Troubleshooting
## ShopHelper does not load the open shop
Confirm it is a supported standard shop window, then close and reopen the shop. Check Debug Log for the detected addon/shop information.
## Automatic opening does not occur
Verify ShopHelper is enabled in AirTabOS Settings > Apps and automatic opening is enabled in ShopHelper settings.
## Quantity is larger than expected
Check whether Stacks is enabled and review the configured stack size.
## Purchase controls are unavailable
Make sure an item is selected, quantity is positive, required currency is available, and no other game confirmation is blocking the shop.
## The game confirmation closes automatically
Disable Auto-confirm Yes/No purchase prompts if you want to approve every game prompt yourself. ShopHelper's own confirmation setting is separate.
