# AirTablet

A modern 16:9 tablet OS for Airi Tsukino's Dalamud venue app suite. The venue
apps are compiled into this one plugin as independently maintained app modules,
so users do not install the bundled versions or individual versions separately.

The app layouts are designed for the tablet form factor.


## Existing plugin data

Open **Settings > Migrate Configs** to copy configuration and saved data from
separately installed versions of supported bundled apps. AirTablet leaves all original
files unchanged and backs up its current app copies before importing.

The default source is the current user's
`AppData\Roaming\XIVLauncher\pluginConfigs` directory. A different source can be
entered on the Migrate Configs page before importing.
